# MTG Deck Gate
# Chat Handover
# 2026-03-08


==================================================
■ 概要
==================================================

MTG Deck Gate は

MTG統率者デッキを作成するための
AI協働型デッキビルドツールである。

本ツールの目的は

強いデッキを最短で作ることではなく

カード理解
シナジー発見
試行錯誤

を通じて

プレイヤーが
デッキビルダーとして成長する体験

を提供することである。


==================================================
■ 設計思想
==================================================

AIは決定しない。

AIは提案する。

最終決定は
プレイヤーが行う。

本ツールは

勝利のみを目的としない。

卓の盛り上がりを生む体験を
重視する。


==================================================
■ 楽しさのロジック
==================================================

楽しさとは

勝利ではなく
卓の盛り上がりである。

重視する要素
