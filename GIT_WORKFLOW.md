MTG Deck Gate
Git Workflow


==================================================
■ 目的
==================================================

本ドキュメントは

MTG Deck Gate の
Git運用ルールを定義する。

設計崩壊
履歴混乱
仕様ロールバック

を防ぐことを目的とする。


==================================================
■ ブランチ構成
==================================================

main

安定版。
完成した仕様・実装のみを保持する。


rebuild/*

再構築ブランチ。
仕様変更・大規模改修を行う。


feature/*

小規模機能追加用。


==================================================
■ 現在の開発ブランチ
==================================================

rebuild/9.10a

MTG Deck Gate
仕様再構築ブランチ。


==================================================
■ main に統合する条件
==================================================

以下を満たした場合のみ
main にマージする。

1
仕様書が凍結されている

2
監査が完了している

3
構造矛盾がない

4
Git構造が整理されている


==================================================
■ コミット方針
==================================================

コミットは

構造単位

で行う。


例

仕様修正
監査修正
export追加
構造整理


==================================================
■ コミット例
==================================================

Freeze specification 2026-03-06

Add audit instruction

Add export documents

Repository structure cleanup


==================================================
■ 仕様書の扱い
==================================================

正本仕様

spec/specification_freeze_20260306.md


仕様修正は
必ずこのファイルに対して行う。


==================================================
■ 禁止事項
==================================================

main に直接コミットしない。


==================================================
■ ブランチ運用
==================================================

通常作業

rebuild/*

↓

安定後

main にマージ
