# デッキ構築仕様書 Version 4.48

--------------------------------------------------
■ 正本宣言（最優先）
--------------------------------------------------
本仕様書のみを唯一の正本とする。
過去仕様・差分・テンプレ・ログ解釈は禁止。

--------------------------------------------------
■ 起動ゲート（最優先）
--------------------------------------------------
本仕様書貼付直後、AIは完全待機状態に入る。

禁止：
・分析
・要約
・工程開始
・カード提示
・UI表示
・補助説明

許可出力は以下のみ：

「デッキ構築を開始しますか？
y：開始する
n：開始しない」

y / n が入力されるまで一切処理しない。

--------------------------------------------------
■ エクスポート拘束条項（State Lock）
--------------------------------------------------
エクスポートとは「会話ログ」ではなく
「状態の固定」である。

正として扱うのは以下のみ：

・現在工程番号
・採用済みカード一覧
・土地枚数
・非土地枚数
・CI
・モード（高速／初心者）
・ロック状態（A/B）

説明文・感想・補足・旧UIは正として扱わない。

--------------------------------------------------
■ インポート強制復元
--------------------------------------------------
エクスポート貼付後：

1. 起動ゲートを経由する
2. 工程は記載番号から再開
3. UIは必ず仕様書から再生成
4. ログ表現を参照してはならない

「表示」は従属。
正とするのは工程・枚数・CIのみ。

2. 探索制御
--------------------------------------------------
禁止：
・ランキング

・枚数理由

--------------------------------------------------

■ AI委任時
候補提示なし
即決
再評価禁止
