# MTG Deck Gate

MTG Deck Gate は  
MTGのデッキ構築を支援するツールです。

目的は

「強いデッキを作ること」

だけではありません。

カードを理解し  
シナジーを発見し  
卓が盛り上がる体験を作る

ことを目的としています。
