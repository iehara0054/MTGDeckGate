■ このリポジトリの目的
仕様書／エクスポート／エラー台帳を分離管理し、
再構築型運用を安定させる。

■ Git運用規則（人間用）
------------------------------------------
・main は常に安定版のみ
・再構築は rebuild/x.x ブランチで行う
・Severityをコミット先頭に書く

例：
[B] UI文言修正（B-03）
[A] aic状態固定再構築（A-02）
[S] 起動ゲート再構築（S-01）

■ 禁止
・台帳未記載のまま改修しない
・mainへ直接大改修しない
・バージョンだけ上げない

※AIはREADMEを参照不要
