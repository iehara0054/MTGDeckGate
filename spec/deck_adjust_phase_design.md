==================================================
【デッキ調整フェーズ設計メモ】
Version：draft
==================================================

■ 目的
--------------------------------------------------
既存のデッキリストを提出し、カードの入れ替え・調整を
AI候補（3択）を使って行えるようにする。

主な対象：
・MTGOデッキを調整したい初心者
・未所持カードを別カードへ置換したい
・100枚にこだわらず試行錯誤したい

※このフェーズは「構築」とは独立する。


==================================================
■ 入口（起動ゲート）
--------------------------------------------------

デッキ構築を開始しますか？

1：新規構築
2：セーブデータで再開
3：カードリストを貼って調整する


==================================================
■ 入力
--------------------------------------------------

ユーザーはカードリストを貼り付ける。

条件：

・枚数制限なし
・MTGO形式でなくてもよい
・1行1カードを基本とする

例：

Arcane Signet
Counterspell
Eclipsed Merrow
Dimir Signet


==================================================
■ 初期処理
--------------------------------------------------

提出されたカードリストを解析し、
番号付きで再表示する。

例：

1. Arcane Signet
2. Counterspell
3. Eclipsed Merrow
4. Dimir Signet


==================================================
■ 基本操作
--------------------------------------------------

r <番号>
指定カードを置換対象にする

例：

r 3

==================================================
■ フェーズ専用“名前空間”
--------------------------------------------------
調整フェーズ専用コマンド（rr / pp）を採用し、ps/r は調整では無効

==================================================
■ 置換候補提示
--------------------------------------------------

AIは3択候補を提示する。

例：

対象：3. Eclipsed Merrow

候補：

1. Merfolk Looter
2. Tomebound Lich
3. Baleful Strix


==================================================
■ 候補探索
--------------------------------------------------

o：似た候補
d：別方向の候補


==================================================
■ 採用
--------------------------------------------------

数字入力で置換確定。

例：

2


==================================================
■ マーク（任意）
--------------------------------------------------

カード名の末尾に

*
＊

が付いている場合、
UI上で強調表示する。

意味は固定しない。
（未所持／要確認／メモ）


==================================================
■ 最終確定
--------------------------------------------------

ps

を入力すると
現在のカードリストを

MTGO形式で出力する。


==================================================
■ MTGO存在注意
--------------------------------------------------

AIはMTGO上だけでなく
全てのMTGカードから候補を提案する。

未所持カードは
稀にMTGO上に存在しない可能性がある。

購入時／インポート時にエラーが出た場合は
別カードへの置換を検討すること。
